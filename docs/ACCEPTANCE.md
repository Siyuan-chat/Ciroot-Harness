# 独立测试与验收方案 D1

本任务负责独立验收；Terra 必须先提交自身的可复现测试结果。命令成功、生成了文件、模型给了答案，均不能单独证明调查目标达成。R 编号对应 [PRD](PRD.md)。

## G0：设计包检查

- 文档相互引用可解析，Schema 是有效的 JSON Schema，示例按对应 Schema 验证。
- 示例为 draft 且无科学测量值；运行预条件明文定义。
- 用户后续要求、工程默认值、实际待定案例信息分开。
- 没有依赖设计者个人 skill 路径才能运行的产品要求；grill-me 的行为要求已写入 PRD。
- 设计交接清楚标注尚无实现、无真实 API 验证、无 GitHub 发布。

## 证据分层

1. 单元/契约：适配器的协议夹具和数据不变量，标注 fixture。
2. 真实组件集成：实际解析器、向量化、检索库、存储和 LangGraph 在本机通信；不能用 fake embedding 代替 A09/A10。
3. 真实外部连接：用户本地配置凭据后，有限额地运行模型与 OpenAlex/EPO；记录实际请求和返回覆盖，凭据始终脱敏。
4. 用户可见验收：本任务按三语指南运行安装/对话/更新/人工处理/报告，并实际打开 HTML 查看布局、文字和链接。
5. 科学效果：独立人工标注集评价，见 G3。

缺少第 3 层凭据不妨碍完成第 1/2 层，但必须标记 online acceptance pending。同理，模型契约测试不能证明不同供应商的真实输出质量。

## G3：聚合物设计案例

案例前冻结：
- 调查具体对象/候选类、关注的设计维度及比较条件。
- 本地参照资料清单及可用内容/来源，独立的候选评价集。
- 人工相关性、指标/条件、重要证据、待人工判断问题的标注。
- 查询范围、来源/语言/地区、预算、评价规则和停止条件。

评价报告至少包括：候选集合内的相关资料召回与筛选准确情况、引用定位和支持正确性、指标/条件提取错误、可比性错误、人工清单覆盖、重复/漏重、运行费用/时间。所有比率给出分子分母和样本构成；不能把已知集合的召回率声称为全球检索召回率。

用户尚未提供这些材料。当前聚合物设计 JSON 是需求草案，不是案例输入已完备的证明。G3 不能先编测量值、论文清单或“优于现有技术”结果再验收。

## G4：GitHub + demo 发布

- G1/G2 通过，G3 有真实记录，阻断项已处理。
- 公共 demo 提供最短运行路径、公开/可再分发的种子或下载清单、固定参数与明确输出示例。
- 可以附 offline replay 便于体验，但必须同时标明它是 replay，并给出真实 live 模式路径。
- 不上传密钥、私有 PDF、用户对话、运行数据库或无法公开的内部判断。
- README 三语一致，安装/命令实际可复现；贡献说明、许可证、依赖/模型声明齐备。
- 在明确 GitHub 目标账号/组织、仓库名和最终分发范围后执行发布；不要提前创建发布版或推送全部工作目录。
