# P4 专利来源替代方案

2026-09-16。用户确认 EPO 注册仍 pending，要求同步近期进展并准备替代方案。本文件为实施设计，未进行替代来源案例检索、未下载正文、未宣称接入通过。

## 首选与切换条件

OPS 审批通过且认证可用时，按 D19_P4_PLAN.md 接入。审批 pending 不反复请求认证；明确拒绝、覆盖不足或持续不可用时可选择下列路径。一次短暂超时不直接认定整个 EPO 不可用。切换前记录原因和生效的来源/预算，原 OPS 计划与失败证据保留。

| 路线 | 发现与检索式 | 正文与身份 | 可证明的范围 |
|---|---|---|---|
| A：OPS 不可用，EPO 公布服务器可用 | Google Patents 网页检索，保存原始表达式、完整结果 URL、时间、过滤、结果 CSV 或实际可见列表 | 从结果中的 EP 公开编号进入 European Publication Server 官方 REST 服务，解析其实际返回的资源链接，优先 XML，再考虑 PDF | 可实现公开网页发现→官方 EP 正文→发现库→中文对照；不等于 OPS API 验收 |
| B：EPO 整体不可访问 | 同上，保留 Google Patents 原生检索式与结果快照 | 保存 Google Patents 对应公开文本 HTML 和页面直接提供的 PDF；来源标为聚合平台，原文版本逐份核对 | 可验证网页采集与证据分析；官方身份/族关系无法核对时明确待核实 |
| C：网页也受限 | 使用用户从官方/公开平台导出的结果 CSV 与公开文本，附检索式、URL、执行时间 | 经现有导入服务进入独立发现库 | 仅“外部检索导入闭环”，不能声称自主 live 检索通过 |

Google 官方帮助支持检索结果 CSV 导出，但本方案不假定存在官方免费搜索 API，不依赖未公开端点或绕过验证码。浏览器登录/验证码由用户处理；实际运行前检查访问条件。

EPO 公布服务器提供 EP A/B 文献 XML、HTML、TIFF、PDF/A 的 REST 获取，不能因此宣称它替代 OPS 的跨地区主题检索与族 API。它仍属于 EPO，所以路线 B 单独覆盖整个 EPO 不可访问的情况。

## 查询与闭环合同

待执行的 Google Patents 原生查询种子：

```text
"anion exchange" membrane
(piperidinium OR "quaternary ammonium") (membrane OR ionomer)
"anion exchange" (alkaline OR stability)
```

不得把这些语法标成已执行 CQL，也不声称与 OPS 字段检索严格等价。每条查询记录 `source`、`syntax`、`expression`、`query_id`、父查询、调整原因、原生字段/过滤、结果 URL、UTC 时间、实际访问范围与候选关联。保留 CSV 原始文件与规范化清单，前二十条不是全量检索。

仍只选择一个相关族、最多两份公开文本、中文双出口，复用 P3 冻结论文证据。公开号/kind、公开日、语言、申请号、优先权和族关联分别记录。平台 family 标识需注明其来源和定义；只有共享优先权线索时记录关系候选，不能直接当作已核实同族。若不能建立有来源支撑的族关系，本阶段的“单族闭环”验收尚未通过。

claims、description、实施例分别标记。HTML 用稳定元素或保存快照上的段落/字符定位，PDF 用物理页，XML 用原元素/段落定位。所有正式主张必须绑定实际取得的公开版本；机器翻译和原文分开。主题检索、编号补查、正文下载分项记录。

## 最小实施与预算提案

- 共用现有 Query/SourceAttempt、发现库与 ReportData，不增加第二套调查状态机。网页采集产物经过公共导入边界，不手改数据库。核心改动由 Terra 单写，运行/角色由 Luna 执行，Astra 独立验收。
- 一次替代小样最多三条查询、每式两次结果页操作；最多保留二十个唯一公开候选。
- 最多查看六个专利详情页；最多两份公开文本。直接正文 HTTP 获取最多八次（失败、重定向、重试计入），累计二十 MiB；不足时停止而非偷偷增额。
- 浏览器只能统计可观察的导航/交互，不能把它等同于底层全部 HTTP 请求数。分别报告六次结果操作、六次详情操作、八次直接获取，不照搬 OPS 的二十次 HTTP 总账。
- 服务角色最多十个、宿主答案及修订最多十四次，复用主方案的总账；若 OPS 已消耗额度，切换不清零。完整研究预算仍待用户确认，本轮只交付方案与 GitHub 同步。

## 验收

检索式可复制、历史可读、结果到公开文本再到引文可追溯；族/版本有依据；至少实际正文包含可分析 claims 或 description；双中文正文有论文与专利双方支持，主张/实施例区别清楚。标准导出及检索历史重开复导出不新增请求。

路线 A/B/C 单独标记通过层级。下载失败、无正文、族关系未证实、官方核验缺失分别显示，不把导入成功替代真实检索/科学验收。达到小样条件即停止，不自动扩展公司监测、三语或新商业 API。
