不包含企业监测、公司业务該非、GUI、完整三语 E01–E07/O01–O04、GitHub 同步或法律结论。原有未提交修改和所有 P3 运行保留。

## 3. 查询准备

以下是计划种子，均未执行，也未宣称服务器语法验证通过；实际宿主规划可以在相同范围内改写，并保留版本与理由：

```text
Q1: ta="anion exchange" and ta=membrane
Q2: (ta=piperidinium or ta="quaternary ammonium") and (ta=membrane or ta=ionomer)
Q3: ta="anion exchange" and (ta=alkaline or ta=stability)
```

Q1 覆盖技术主题，Q2 覆盖阳离子路线，Q3 是耐碱方向的候选补查。第一轮不强制把电导率和稳定性同时放入筛选条件，避免摘要未提性能而直接丢弃相关专利。无申请人、年代或地区硬过滤；正文选取优先 EP/WO 不等于主题检索限定地区。分类号需从实际候选/官方分类获得依据后才使用，不预造分类号。

执行时最多启用三个查询版本（含修订），每式最多两页、每页五条；整体最多保留二十个唯一公开候选。选择一个族及最多两份正文，记录相关性、正文可用性与选族理由；未选族仍保留候选身份及排除/未深入理由。若没有可用相关正文，交付覆盖缺口，不自动换来源或另开新运行。

## 4. 一次小样预算提案

| 项目 | 上限与口径 |
|---|---|
| OPS 全部 HTTP 尝试 | 20 次，认证、分页、失败、重试均计入；跨预检/实际运行累计 |
| 认证 | 2 次，首认证和最多一次必要刷新；有效 token 复用，不写日志 |
| 主题检索 | 6 次，至多三个式各两页；查询修订消耗同一额度 |
| 族/书目/正文可用性 | 6 次，共享；保留族来源及响应中的身份语义 |
| claims/description XML | 4 次，最多两公开文本各两章节；缺失单独记状态 |
| 额外失败重试储备 | 2 次，包含在总计 20 内；认证/权限错误不盲重试 |
| 接收体积 | 累计 20 MiB，单响应最多 5 MiB；失败/重试收到的字节也计入 |
| PDF | 首轮不下载；XML不足时记录缺口，PDF降级另行确定请求构成 |
| 服务角色任务 | 最多 10 个；预计规划、专利筛选、分析、技术相关性、综合、双出口写作、核查等，按实际服务任务计账 |
| 宿主答案生成及修订 | 最多 14 次，含上述任务答案与修订，非额外 14 次；由运行台账累计 |
| 单请求超时 | 30 秒；限流退避有界并记录，不能绕过总额度 |

预算是工程停止上限，不是费用保证或成功保证；不继承 P3 余量，不通过换 run 清零。代码实现/离线协议测试与真实研究角色生成分别记录，不假称掌握完整订阅 token 账单。官方文档浏览已执行，不属于 OPS 数据 API 请求。

## 5. 最小实施合同

1. Terra 单写核心：复用现有 runtime/Query/SourceAttempt，增加 EPO 配置、来源能力与缺凭据诊断；认证缓存与每次 HTTP 的预留/结算、错误分层、有限分页、原始 XML 保存。

3. 复用独立发现库导入与公共 attach；原文、分析 facts、正式引用和标准报告连通。无需重建原库或扩展第二套状态机。
4. 查询及执行历史由持久记录机械导出，重开复导出无需网络。秘密值、认证 header/token 不写历史；使用脱敏请求参数和响应覆盖统计。
5. Luna 单写运行脚本/执行台账及角色产物，按固定候选自检后交付。Astra 负责设计、集中科学反馈和独立验收。尚未派发实现；开始时传递完整文件归属与检查点。

## 6. 验收与停止

- 离线：真实接口形状的明确 synthetic XML 测试认证失败、空结果与失败区分、分页/预算、同族不同 kind、章节缺失、引用 locator；仅检查受改动影响的既有 OpenAlex/导出路径。
- live：一条正常服务路径实际经过 EPO 检索、族关联、公开正文、发现库、论文对照与中文双出口；所有请求可追溯，未获取内容不伪称全文。
- 科学：逐条正式主张核对身份、原句/上下文、试验条件、权利要求/说明书/实施例角色及论文对照。无可比条件不排名；材料不足必须形成具体待核实项。
- 交付：读回两份正文、标准导出与新增检索历史；从检索式找到请求、候选、所选公开文本和正式引文。重开读回与复导出不推进调查、不新增网络和预算。
- 达到本阶段标准即停止；这不等于完整 P4 三语覆盖验收。预算耗尽或来源条件缺失时保留 partial/blocked 证据，不启动替代 run。
