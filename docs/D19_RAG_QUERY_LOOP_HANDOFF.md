4. **新池 → 正式事实 → 双正文。** 新论文和专利分别保存原文及独立版本，导入发现库并检索，使用已有公共 attach 绑定文档身份/内容指纹。技术报告和综述既可引用本地基准，也可引用两类新材料；权利要求、说明书、实施例和论文实验分开。条件不相容、表格/图式无法保真、来源截断均保留 `partial` 或人工缺口。
5. **固定候选与验收。** 离线协议/fixture 测试先行；构建 wheel 并在隔离安装路径检验实际公共入口。真实小样预算须先形成可审阅的数值方案并获得批准，随后以一个固定 run 验证全过程。实施者自测后交另一审阅者独立验收；只重查受改动影响的层。

## 建议验收口径

- 规划记录至少展示一条由**真实本地 RAG 命中**支撑的来源查询：非空 `input_refs` 指向正确文档版本与原文位置，查询术语和限制可解释；两个来源的查询语法分别校验。
