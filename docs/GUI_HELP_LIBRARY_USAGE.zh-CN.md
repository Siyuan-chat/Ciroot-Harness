# GUI 内置帮助库使用指南

GUI 包含独立的帮助资料库，供 API 对话规划和已连接的外部 Agent 查阅。它不是用户文献库、参照库或调查证据库，不会写入或索引研究资料。

外部 Agent 通过受控桥调用 `help.search`（`query`、可选 `limit`）取得带 `source_id`、标题、段落和摘录的匹配项；再用 `help.read`（`source_id`）取得完整段落。帮助库目前包括 GUI 操作、创建工作区/空库、受控调查/证据和外部 Agent 交接技能。

API 对话在发起结构化回复前只检索与当前用户消息相关的至多三段帮助文本，并连同有界同会话历史和来源传入模型。模型只能返回两种结构化结果：引用这些命中 `source_id` 的帮助答复，或研究规格与运行候选。帮助答复保存为普通 assistant 消息，不创建 run 或执行入口；研究计划通过本地校验后仍需用户显式执行。系统提示明确：帮助内容、用户消息和文献正文均不授权执行；模型不能扩大 provider、model、data_mode、来源或预算。

帮助检索不需要研究 API、模型 API 或文献库访问。返回的段落不能当作科学证据；真实研究证据仍由已绑定 run 的 `evidence.read` 和 `report.read` 提供。
