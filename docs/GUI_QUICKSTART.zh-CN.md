# CirootHarness 图形界面使用说明（Windows）

本说明对应 Windows 桌面候选。界面名称为 **CirootHarness**，可执行文件仍叫 `ResearchHarnessGUI.exe`。

## 下载与首次启动

1. 从仓库 Releases 下载 Windows ZIP，完整解压 `ResearchHarnessGUI` 文件夹。不要只取出 EXE；旁边的 `_internal` 是程序依赖。
2. 双击 `ResearchHarnessGUI.exe`。应用只监听本机回环地址，默认工作区建在程序目录旁的 `ResearchHarnessGUI-workspace`；它是你的数据目录，升级程序时不要删除。
3. 首次启动按系统语言选择中文或日文；其他系统语言显示英语。点右上角 `⋯` 可手动改语言，选择会在本机保存。原始文献标题和正文始终保持来源语言。

Windows 需要可用的 WebView2 运行环境。若应用没有打开，先确认解压完整、Windows 已安装 WebView2 运行时，并从解压目录直接启动 EXE。

## 工作区与文献

点顶部“＋新建工作区”，填写名称；说明可留空。进入工作区后，在“文献库”中点“新建文献库”，填写名称并创建。选择新库，点“导入 PDF / TXT”添加文件。单文件上限 20 MiB；TXT 须为 UTF-8，PDF 须含可提取文字。扫描版 PDF 目前不做 OCR。导入后的资料、原文件及页码或行号定位保存在当前本机工作区，重启应用后仍可查看。

左侧“文献库”显示当前选定库的文献列表；切换工作区、文献库和分组后，列表随上下文更新。点文献“查看详情”可打开详情抽屉，再关闭返回列表。输入关键词可在所选库中做本地基础文本检索；它不是向量语义检索，也不跨库。选定库没有资料时列表为空。发布 ZIP 不含作者本机的 23 篇文献、原始 PDF 或向量模型缓存。

已有 RAG 工作区可通过启动参数关联，例如：

```powershell
& '.\ResearchHarnessGUI.exe' --library-workspace 'C:\path\to\your-rag-workspace'
```

路径应指向你自己的、已建立索引的 RAG 工作区。向量检索还需要相应模型缓存；不要将文献原件、密钥或工作区复制进程序目录后上传。

## Agent 对话与调查

右侧“对话”是可收起的侧栏；展开后可从会话列表选择旧会话或新建会话。窄窗使用顶部“内容 / 对话”切换，返回内容后仍可查看文献列表。会话输入框适合直接询问使用方法、范围及预算；内置帮助库与研究文献库分开，帮助答复不是科学证据。

初次体验建议保持 **synthetic / 离线 scripted** 执行器，在输入框提出研究问题并发送。Agent 先形成规划；只有用户点“执行”，才创建调查任务。此路径使用内置合成资料，不会调用真实研究 API 或付费模型。报告与证据只能按实际任务状态查看，`partial`、等待及失败不代表完成。

API 执行器需要在“设置”中提供对应模型密钥和模型配置；真实调用可能收费。凭据只在当前应用进程中保存。外部 Agent 模式需要兼容的客户端主动连接并领取消息；显示等待连接时，不能视为它已收到消息。不要把合成离线运行当成真实文献调查结果。

## 数据、迁移与当前限制

- 升级时保留 `ResearchHarnessGUI-workspace`，只替换程序文件夹；迁移到另一台机器时，单独迁移工作区并重新指定文献库和模型缓存路径。
- 发布包没有本机路径配置、API 密钥、原始文献或研究结果。首次启动不应期待看到演示机的 23 篇文献。
- 当前候选的本地 PDF/TXT 导入与基础检索不等于完整 RAG 验收；原生 WebView2 全流程、跨库检索及真实模型/来源 API 端到端调查仍未完成验收。
