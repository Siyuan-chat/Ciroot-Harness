# 整合候选：激活与验收清单

本轮用户选择离线候选。此清单记录待激活条件；工程组件的实际完成状态以 [阶段记录](INTEGRATION_STAGE.md) 为准。

## 研究引擎

PaperQA2 和 STORM 分别使用独立锁定环境。安装时提供本地核心 wheel；运行时配置 `research_engine.python_executable`。缺少包、版本不匹配或能力检查失败，应显示明确诊断，不能自动安装或绕过核心调用账本。

真实运行需新建运行并明确 ProviderProfile、模型名、密钥环境变量名与数值额度。实际模型、嵌入、元数据及下载共享运行额度；缓存命中单独记录。已有历史运行不重置额度。未知调用保留占用，不自动重发。

| 项目 | 激活或验收所需证据 |
| --- | --- |
| PaperQA2 | 固定候选的实际库离线检查；随后经授权的真实模型运行、逐主张引用与语义复核 |
| STORM | 固定候选的实际库离线检查；受控检索和模型接口，不隐式下载或访问外网 |
| 专利结构分析 | 明确出版物和版本、完整原文绑定；领域解释与算法结果分别核查 |

## 多地区来源

免费能力纳入交付范围；不申请账号、购买服务或发送试用材料。服务规范缺失与凭据缺失分别记录，不能用假接口替代。

| 来源 | 当前待激活条件 |
| --- | --- |
| JPO | 官方接口所需 token／权限；OPD 另需相应授权；号码补充与关键词搜索能力分别声明 |
| EPO OPS | 既有客户端和冻结案例继续保留；新增真实运行使用新预算和有效凭据 |
| EPO Publication Server / Linked Data | 组件接入核心后的权限与预算核验；真实公开调用仍待授权；未确认法律事件路径保持待规范 |
| USPTO ODP | 有效 API key、授权域及文件可访问性；离线官方响应样例不算真实查询 |
| KIPRIS Plus | 具体服务权限、有效凭据及官方安全传输规范；不能把密钥发送到仅确认的 HTTP 地址 |
| TIPO | 账号权限及确认的认证响应解析规范；不猜测 token 字段或有效期；案件、关联与文件接口分别核验 |
| GPSS | 官方业务 API 的请求、认证和响应规范；宣传材料中的能力介绍不足以生成请求 |
| WIPO Pearl | 当前 B2B 业务 API 规范和授权；术语、对应词与记录能力分别声明 |

## 部署与评测

Windows 必须在实际 WebView2 中完成配置、调查、原文查看、复核、导出、退出与重开。浏览器/API 检查不能替代该记录。可选研究环境使用已安装 wheel，不能依赖开发目录。

Docker 验收需要有 Docker 的宿主实际构建镜像、启动、停止、重建并检查持久卷。本机没有 Docker 时只交配置候选并记录未验收，不宣称镜像已构建。

公开 Demo 只使用合成或再分发许可明确的冻结材料，服务端拒绝真实模型、抓取、上传、管理写操作和宿主工具。交镜像配置与说明；本轮不发布公网。

科学效果按 [评测协议](INTEGRATION_EVALUATION.md) 逐项标注。未完成人工支持判定、真实成本和实测复核耗时前，保持未评判，不生成性能提升结论。
