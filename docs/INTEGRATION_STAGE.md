## 接口和部署约定

- ResearchEngineAdapter 输入绑定 run、task version、资料 scope、ProviderProfile 和预算；输出 draft sections、claims、citations、coverage gaps 和 trace。引擎不写正式业务数据库。
- PaperQA2/STORM 是可选子进程环境，JSONL 与核心通信；通过公开模型/检索接口向核心申请调用，不能直接持有服务凭据或绕过账本。精确依赖版本、许可证与隐含网络行为在引擎阶段锁定。
- 引用映射必须匹配 document/version/parse revision/locator；不唯一或缺原文进入复核。新解析不覆盖旧证据；重放不重新检索。
- 新报告事实块从已接受断言组织，自由正文保留草稿；定位、引句、语义支持分别记录；历史冻结报告不追溯改写。
- Windows 保留轻量 EXE，并配置独立研究运行环境。Docker 单进程复用现有 FastAPI，资料/工作区挂卷。Demo 使用独立 profile，在服务端禁真实模型、抓取、上传、管理与宿主工具，只读隔离案例。
- 可选研究环境安装时接收本地核心 wheel 并记录哈希；运行配置使用 `research_engine.python_executable`，通过已安装包的模块入口启动工作进程。运行时不安装依赖，不依赖源码目录注入。
- 公开 Demo 只交容器和部署说明，本轮不绑定云平台、不发布公网。单用户自托管不等于多租户在线研究。
- 真实运行必须有具体模型/来源和数值预算；各引擎共用额度。开发回归默认禁网；不购买服务、申请账号、启动监测或发布 GitHub。
