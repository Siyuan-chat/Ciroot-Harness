# Architecture assets

`cirootharness-architecture.en`, `.zh-CN`, and `.ja` are the public README architecture overview. The PNGs share a 1800 × 1050 canvas. Their editable SVG sources use the same card geometry, palette, icons, workflow and review loop; only localized text and line wrapping differ.

The common layout follows the user-provided Chinese and Japanese reference images. The editable reconstruction and overflow corrections were approved for this documentation change. PNGs are rendered directly from their corresponding SVG in a browser; keep both formats synchronized after editing. Use Arial with Microsoft YaHei / Yu Gothic fallbacks to render Latin, Chinese and Japanese text.

`harness-overview.svg` and `harness-overview.png` remain the detailed/internal engineering architecture, referenced by [System design](../SYSTEM_DESIGN.md). They are retained unchanged. Public diagrams explain the design; [Engineering status](../DEVELOPMENT_STATUS.md) defines implemented and accepted capability boundaries.
